# 사용자 동기 성향 파악

작성일: 2026-11-12
관련 화면: `../mvp-prototype.html` (처음 열면 나오는 성향 질문, 홈의 동기 카드)
관련 요구사항: #35 안 한 날을 지적하는 방식이 아니라 하고 싶은 마음이 생기게 독려해야 한다

## 1. 출발점

같은 "연속 기록" 장치라도 사람에 따라 반응이 다르다.

- 연속을 채우는 것 자체에서 성취감을 느끼는 사람
- 오늘 하루를 해냈다는 것에서 성취감을 느끼는 사람
- 연속이 끊기면 의욕을 아예 잃어버리는 사람

그렇다면 처음에 사용자의 성향부터 파악하고, 그에 맞게 기록을 보여 주는 방식을 바꾸는 것이 낫지 않을까 하는 질문에서 시작했다.

## 2. 근거: 스트릭은 모두에게 좋은 장치가 아니다

- **스트릭이 끊긴 사용자는 앱을 아예 떠날 가능성이 높다.** 또 스트릭을 복구할 수 있다는 걸 알면 유지하려는 의욕이 오히려 떨어진다. (Silverman 외, 2023, *Journal of Consumer Research*, "On or Off Track")
- **스트릭과 알림은 반복을 돕지만 앱에 기대게 만든다.** 그만큼 쉽게 무너지고, 끊기면 그대로 떠난다. (Northumbria 대학, 습관 앱 Lift 사용자 질적 연구)
- **하루 빠져도 습관 형성에는 큰 지장이 없다.** (UCL, Lally 외) 결국 "끊기면 끝"은 실제 습관이 아니라 사람의 해석에서 생기는 문제다.

> 블로그에 자주 나오는 "63%가 스트릭 불안 때문에 이탈" 같은 수치는 원문 출처를 확인하지 못했다. 인용하지 않는다.

## 3. 성향이 얼마나 다양한가: 관련 이론

처음에 떠올린 3가지는 사실 서로 다른 두 축이 섞인 것이다.
**무엇에서 성취감을 느끼나**(연속 / 하루)와 **실패에 어떻게 반응하나**(무너짐 / 회복).

| 이론 | 핵심 | 앱에 주는 의미 |
|---|---|---|
| "에라 모르겠다" 효과 (금욕 위반 효과, Polivy & Herman / Cochran & Tesser 1996) | 작은 실수 하나를 완전한 실패로 받아들이고 전부 놓아 버림 | "연속이 끊기면 의욕 상실" 유형의 정체. 실수해도 자신을 탓하지 않는 태도(자기 연민)가 있으면 회복이 빠르다 |
| Four Tendencies (Gretchen Rubin) | 기대에 반응하는 4가지 방식. 원칙형(안팎 모두 지킴), 납득형(이유가 있어야 함), 약속형(남이 봐야 함), 반골형(시키면 안 함) | 알림·목표·규칙을 어떻게 줄지. 대중서 이론이라 학술적으로 검증되지는 않았다 |
| Hexad 게이미피케이션 사용자 유형 (Marczewski, Tondello 외 2016) | 성취형·사회형·자유영혼형·이타형·보상형·파괴형 6가지. 검증된 24문항 설문이 있다 | 성취 말고도 "같이 하기", "다양하게 해 보기" 같은 동기가 따로 있다. 상업적으로 쓰려면 연구진에게 허락을 받아야 한다 |
| 조절 초점 이론 (Higgins) | 얻는 기쁨으로 움직이는 사람과 잃는 두려움으로 움직이는 사람 | 스트릭은 잃는 두려움을 자극하는 장치다. 두려움 쪽 사람에게 강하게 먹히는 대신 끊길 때 크게 무너진다 |
| 성취 목표 지향 | 숙달형(어제의 나보다 나아짐), 수행형(숫자·남과 비교) | 성장 그래프를 보여 줄지, 순위를 보여 줄지 |
| 새출발 효과 (Dai, Milkman, Riis 2014) | 월요일·1일·새해처럼 시작점 같은 날에 다시 시작하려는 의욕이 생김 | 끊긴 사람을 다시 불러올 타이밍 |

### 앱에서 쓸 성향 정리

| 성향 | 특징 | 위험도 |
|---|---|---|
| 연속 수집가 | 끊기지 않는 기록 자체가 기쁨 | 보통 |
| 오늘 완료형 | 오늘 체크하면 충분 | 낮음 |
| 올오어낫싱형 | 한 번 끊기면 이탈 | **높음** |
| 총량 누적형 | 연속보다 "총 100회" 같은 누적 | 낮음 |
| 성장 추적형 | 무게·시간이 느는 게 보여야 함 | 낮음 |
| 약속형 | 누가 봐 주거나 같이 해야 함 | 보통 |
| 반골형 | 알림·목표를 강요하면 오히려 안 함 | 보통 |
| 납득형 | 왜 해야 하는지 근거가 필요함 | 낮음 |
| 경쟁형 | 남과 비교해야 의욕이 생김 | 보통 |
| 탐험형 | 반복하면 질려서 다양성이 필요함 | 보통 |
| 새출발형 | 끊겨도 "월요일부터"라면 돌아옴 | 보통 |

## 4. 파악 방법에 대한 판단

- **질문이 길면 그것 때문에 떠난다.** 6문항, 30초 안에 끝낸다. 건너뛰기를 둔다.
- **사람은 자기를 잘 맞히지 못한다.** 질문 답은 첫 추정으로만 쓰고, 실제 행동으로 보정한다.
- **딱 한 유형으로 나누지 않는다.** 축마다 따로 답을 받고 조합해서 쓴다.
- **"연속 기록 좋아하세요?"처럼 직접 묻지 않는다.** 상황을 주고 고르게 한다.

## 5. 질문 (프로토타입에 반영됨)

질문 하나가 축 하나를 맡는다.

**Q1. 무엇에서 성취감을 느끼나 (focus)**: 운동 앱을 열었을 때 제일 기분 좋은 화면은?
- "23일 연속 달성" → 연속 수집가
- "오늘 할 일 완료!" → 오늘 완료형
- "이번 달 총 18회" → 총량 누적형
- "지난달보다 스쿼트 +10kg" → 성장 추적형

**Q2. 실패에 어떻게 반응하나 (fail)**: 가장 중요한 질문. 열흘 연속 하다가 어제 하루를 빼먹었다. 오늘 기분은?
- 아깝지만 오늘 다시 하면 되지 → 회복형
- 다시 1일부터라니… 하기 싫다 → 올오어낫싱
- 별 생각 없다 (원래 연속은 신경 안 씀) → 무관심
- 이번 주는 망했고, 월요일부터 다시 → 새출발형

**Q3. 무엇이 움직이게 하나 (drive)**: 운동을 제일 꾸준히 했던 때는?
- 내가 세운 계획이 있을 때 → 원칙형
- 친구나 트레이너와 약속했을 때 → 약속형
- 왜 해야 하는지 납득했을 때 → 납득형
- 아무도 시키지 않았을 때 → 반골형

**Q4. 알림 반응 (nudge)**: "오늘 운동 아직 안 했어요!" 알림이 오면?
- 고마워요, 덕분에 해요 / 좀 찔리지만 도움은 돼요 / 짜증 나서 오히려 하기 싫어져요

**Q5. 혼자 / 함께 (social)**: 혼자 조용히 내 기록 보기 / 친구와 서로 인증하기 / 다른 사람들과 순위 비교하기

**Q6. 반복에 대한 태도 (variety)**: 같은 루틴을 한 달 내내 하면? 익숙해서 좋다 / 2주쯤 지나면 질린다

### 대표 성향 정하는 규칙

1. Q2가 "올오어낫싱"이면 → **내 페이스를 지키는 사람** (실패 반응이 가장 우선)
2. Q2가 "새출발"이면 → **다시 시작이 쉬운 사람**
3. 그 외에는 Q1을 따른다 → 이어가는 사람 / 오늘을 해내는 사람 / 차곡차곡 쌓는 사람 / 어제보다 나아지는 사람

Q3~Q6은 대표 성향을 바꾸지 않고, 알림·추천·공유 방식 같은 세부 설정에 반영한다.

## 6. 성향별로 앱이 달라지는 점

**홈의 동기 카드** (프로토타입에 구현)

| 대표 성향 | 카드 제목 | 보여 주는 것 |
|---|---|---|
| 이어가는 사람 | 계획 연속 달성 | 연속 일수, 최고 기록, 최근 14일 |
| 오늘을 해내는 사람 | 오늘 할 일 | 오늘 계획 하나와 완료 체크만. 연속 숫자 없음 |
| 차곡차곡 쌓는 사람 | 쌓인 운동 | 줄지 않는 누적 일수, 다음 목표(10·20·30·50·100일)까지 남은 수 |
| 어제보다 나아지는 사람 | 성장 기록 | 지난달 대비 러닝 거리, 페이스 변화, 최고 무게 |
| 내 페이스를 지키는 사람 | 이번 주 목표 | "이번 주 X/4회". 빠진 날은 표시하지 않고, 누적은 줄지 않음 |
| 다시 시작이 쉬운 사람 | 이번 주 목표 | 위와 같은 주간 카드에 "새로운 한 주" 문구 |

**세부 설정** (결과 화면에 안내만, 아직 기능 구현은 없음)

- 알림: 하루 한 번 / 저녁에 한 번 부드럽게 / 보내지 않음
- 원칙형: 내가 세운 계획을 맨 위에 / 약속형: 함께할 사람·모임 추천 / 납득형: 운동마다 이유와 효과 설명 / 반골형: 목표를 정해 주지 않음
- 함께: 친구 인증 / 경쟁: 순위 (출시 후)
- 탐험형: 2주마다 새 루틴·종목 제안

## 7. 행동으로 보정하기 (다음 단계)

질문 답과 실제 행동이 다를 때 보정할 신호들이다.

| 신호 | 의미 | 조치 |
|---|---|---|
| 연속이 끊긴 뒤 3일 넘게 앱을 열지 않음 | 올오어낫싱 가능성 | 주간 목표 카드로 바꾸자고 제안 |
| 연속이 끊긴 다음 날 바로 기록 | 회복형 | 그대로 유지 |
| 월요일·1일에만 돌아옴 | 새출발형 | 주 시작에 맞춰 다시 시작 메시지 |
| 알림을 끄거나 알림 뒤에 앱을 지움 | 반골형 또는 알림 과다 | 알림 줄이기 |
| 기록 화면에서 성장 그래프를 오래 봄 | 성장 추적형 | 성장 카드 제안 |
| 모임 참여 주에만 기록 | 약속형 | 모임·친구 추천 강화 |

## 8. 주의할 점

- 스트릭을 복구하는 기능은 연속 수집가의 의욕을 오히려 떨어뜨릴 수 있다 (Silverman 외). 넣는다면 신중하게.
- Four Tendencies는 검증된 심리 검사가 아니다. 질문을 만드는 참고로만 쓴다.
- Hexad 설문 원문을 상업적으로 쓰려면 HCI Games Group의 허락이 필요하다. 현재 질문은 원문 문항을 쓰지 않고 새로 만들었다.
- 결과 화면의 성향 이름은 사용자에게 보여 주는 것이라 긍정적인 표현으로 바꿨다. 예를 들어 "올오어낫싱형"은 "내 페이스를 지키는 사람"으로 보여 준다.
