# 준비·마무리 스트레칭 추가, 탭 전환 이동 위치·부드러움 개선, 측정 기록 조회 단순화

## 체크리스트
- [x] 측정 기록: '최근 5회' 버튼과 문구 제거 (아무것도 고르지 않은 기본 상태가 최근 5회)
- [x] 기간 버튼은 1개월 · 3개월 · 직접 설정만 남김 (6개월·1년 제거). 고른 버튼을 다시 누르면 기본으로
- [x] 직접 설정은 최대 3개월: 달력에서 고를 수 있는 날짜를 서로 3개월 안으로 묶고, 넘기면 안내
- [x] 아래로 내려가 있을 때 운동·식단을 누르면 맨 위가 아니라 탭 줄이 맨 위인 위치까지만 이동 (그보다 위에 있으면 이동 없음)
- [x] 화면 이동을 직접 만든 애니메이션으로 교체: 거리에 따라 0.35~0.75초, 천천히 출발해 천천히 멈춤. 손가락·휠로 움직이면 바로 멈춤
- [x] 스트레칭 데이터: 근육별 준비·마무리 동작(ST_MUSCLE), 종목별 준비·마무리(ST_SPORT: 러닝·수영·축구·풋살·농구·배드민턴·테니스·배구·족구·복싱·등산·자전거·클라이밍·기본)
- [x] 헬스: 루틴 종목이 쓰는 근육(EX_INFO)에 점수를 매겨 많이 쓰는 근육부터 동작을 자동으로 고름 → 종목을 바꾸면 스트레칭도 따라 바뀜
- [x] 운동 탭 각 종류 화면에 '준비 · 마무리 스트레칭' 카드 (헬스는 펼친 루틴마다). '수정'을 누르면 루틴 수정처럼 동작·양 고치기, 빼기, 추천 목록에서 추가, 직접 적기, '자동 추천으로 되돌리기'
- [x] 오늘의 운동 상세에 준비 운동·마무리 한 줄 요약
- [x] 운동 중 화면(헬스·러닝·단체)에 준비 운동 / 마무리 스트레칭 체크 카드 (건너뛰어도 됨). 저장한 기록에 한 개수를 남기고 기록 상세에 '준비 운동 4/5 · 마무리 3/4'로 표시
- [x] 단체 운동·축구 기본 루틴에 들어 있던 '동적 스트레칭', '쿨다운 스트레칭' 항목은 스트레칭 카드로 옮겼으니 제거
