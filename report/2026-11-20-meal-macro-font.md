# 기록 탭 식단 영양소 수치 폰트 축소

## 체크리스트
- [x] 기록 탭 > 날짜별 식단 기록의 탄수화물·단백질·지방 카드 위치 확인 (`dayCard`)
- [x] 영양소 카드에 `macro` 클래스 추가
- [x] `.rstat.macro b` 규칙 추가: 수치 폰트 20px → 16px, 줄바꿈 방지(`white-space:nowrap`)

## 요약
- **무엇을**: 식단 기록의 영양소 수치(예: `120 / 150g`) 글자 크기를 줄였습니다.
- **왜**: 3열 그리드에서 탄수화물 수치가 20px로 표시되어 좁은 화면에서 줄바꿈이 발생했습니다.
- **어떻게**: 탄수화물만이 아니라 같은 카드의 단백질·지방 수치도 같은 16px로 맞췄습니다. `.rstat`는 운동 기록의 통계 행(운동 시간·종목·세트 등)과 같이 쓰는 클래스라서, 그쪽에는 영향이 없도록 식단 영양소 카드에만 `macro` 수정 클래스를 붙였습니다.

## 남은 이슈
- 운동 기록 통계 행(20px)과 글자 크기가 달라졌습니다. 기록 탭 전체를 통일하려면 `.rstat b` 자체를 줄이면 됩니다.
