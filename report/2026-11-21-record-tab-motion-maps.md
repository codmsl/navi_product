# 기록 탭: 탭 전환 이동 다듬기, 체성분 그래프 점 정리, 러닝 경로·축구 움직임 그림

## 체크리스트
- [x] 아래로 내려간 상태에서 운동·식단 탭을 누르면 맨 위로 부드럽게 이동 (예전에는 바로 맨 위로 바뀜)
- [x] 다시 그릴 때 내용이 짧아져 위치가 밀리던 것 수정: 맨 아래 빈 자리를 필요한 만큼 덧대고 이동이 끝난 뒤 줄임 (770 → 770 유지 후 0으로 이동 확인)
- [x] 운동 종류·체성분 선택 시 목표 달성률이 비쳐 보이지 않게: 고정 줄 배경 막을 화면 폭 끝까지 깔고(::before), 아이패드는 안쪽 여백(16px)에 맞춰 고정 위치 조정
- [x] 체성분 그래프: 점은 가장 최근 기록만 표시. 다른 지점은 누르거나 마우스를 올릴 때만 잠깐 표시
- [x] 러닝 기록: '이동 경로' 그림 (한 바퀴 도는 길·한 방향 길, 1km 표시, 출발·도착 표시, 지도 느낌의 강·길). 인터벌은 400m 트랙
- [x] 축구·풋살 기록: '경기장 위 움직임' 그림 (경기장 규격 반영, 오래 머문 곳 히트맵 + 지나간 길), 주로 뛴 곳·전력 질주 횟수
- [x] 구기 종목의 '지난번과 비교'가 다른 종목(축구↔풋살)과 비교되던 문제 수정
- [x] 아이패드에서 경로·경기장 그림 최대 높이 제한

## 요약
- 움직임 그림은 예시 데이터라 기록마다 날짜로 정한 난수로 만든다(같은 기록은 항상 같은 모양). 실제 앱에서는 휴대폰·워치 GPS 기록으로 그린다는 안내를 붙였다.

## 남은 이슈
- 아이패드에서는 그래프가 넓게 늘어나며 글자도 함께 커진다 (기존 그래프도 같은 방식). 필요하면 아이패드용 그래프 크기를 따로 잡을 것
- 체성분 측정 기록 목록 표시 방식은 의견 드린 뒤 결정
