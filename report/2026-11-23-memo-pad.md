# 메모장 버튼

## 체크리스트
- [x] 왼쪽 버튼 줄(처음부터·다크 모드·아이패드) 아래에 '메모장' 버튼 추가
- [x] 버튼을 누르면 메모장이 열리고, 다시 누르면('메모장 닫기') 닫힘
- [x] 적는 대로 자동 저장(0.3초 뒤, 입력 칸을 벗어날 때, 페이지를 닫을 때). 위쪽에 '저장 중…/저장됨' 표시
- [x] 메모 내용·열림 상태·크기(오른쪽 아래 모서리로 조절)를 이 브라우저(localStorage `mvp-prototype-memo-v1`)에 기억
- [x] '처음부터'를 눌러도 메모는 지워지지 않음
- [x] 기본 크기를 폰 왼쪽 빈 자리에 맞춰 폰 화면을 가리지 않게 함
- [x] 아이패드 화면(iframe)에서는 메모장 코드를 돌리지 않음

## 요약
- 무엇을: 프로토타입 옆에서 쓸 수 있는 메모장을 버튼으로 열고 닫게 했습니다.
- 왜: 프로토타입을 보면서 떠오른 내용을 바로 적어 두고, 새로고침이나 다시 열어도 남아 있게 하기 위해서입니다.
- 어떻게: 기존 다크 모드·아이패드 버튼과 같은 방식(고정 버튼 + localStorage)으로 만들었습니다.
  같은 파일을 아이패드 화면으로 한 번 더 띄우기 때문에, 그 안에서도 메모장 코드가 돌면 페이지를 닫을 때 예전 내용으로 덮어쓰는 문제가 있어 아이패드 화면에서는 건너뛰게 했습니다.

## 검증 (헤드리스 크롬)
- 처음엔 닫힘 → 버튼으로 열림, 버튼 글자 '메모장 닫기'
- 입력 후 새로고침 → 열린 채로 내용 그대로
- 닫고 새로고침 → 닫힌 채로 내용 그대로
- '처음부터' 후에도 내용 그대로
- 스크립트 오류 없음

## 남은 이슈
- 저장은 이 브라우저에만 됩니다(다른 브라우저·기기와는 공유되지 않음).

# 수정: 아이패드와 메모장 번갈아 보이기

## 체크리스트
- [x] 메모장 버튼 제거. 아이패드 버튼 하나로 아이패드 ↔ 메모장 전환
- [x] 아이패드를 보이면 메모장이 숨고, 아이패드를 숨기면 그 자리(폰 오른쪽)에 메모장이 나타남
- [x] 버튼 글자는 지금 안 보이는 쪽 이름: '메모장 보기' / '아이패드 보기'
- [x] 메모장 크기를 폰 높이에 맞춤(380×864), 크기 조절·크기 저장은 없앰
- [x] 내용은 그대로 이 브라우저에 저장(같은 저장 키), 어느 쪽을 보고 있었는지는 기존 아이패드 설정이 기억

## 검증 (헤드리스 크롬)
- 처음: 아이패드 보임, 메모장 숨김, 버튼 '메모장 보기'
- 버튼 → 아이패드 숨김, 메모장 보임, 버튼 '아이패드 보기'
- 입력 후 새로고침 → 메모장 보인 채 내용 그대로
- 다시 버튼 → 아이패드로 돌아감, 새로고침·'처음부터' 후에도 내용 그대로
- 스크립트 오류 없음
