# 기록 탭: 데이터 입력 버튼 제거, 축구·수영 기록 추가, 종목 칩 가로 스크롤, 자동 화면 이동

## 체크리스트
- [x] 화면 밖 '데이터 입력' 버튼과 무작위 데이터 생성 코드(`randomFill`, `applySample`) 제거
- [x] 예전에 버튼으로 넣어 브라우저에 저장된 무작위 기록(`setup.sample`)은 열 때 버리고 예시 기록을 쓰도록 변경
- [x] '처음부터'를 눌러도 지난 기록(운동·식단·체성분·목표·종목별 무게·러닝 진행)은 남도록 변경 (오늘 먹은 음식·물·영양제·냉장고·참여 모임만 비움)
- [x] 예시 기록에 축구 6회(토요일), 수영 8회 추가 (조금씩 나아지는 흐름)
- [x] 기록 종류 `swim`(수영) 추가: 색·점·태그, 그날 기록(거리·시간·100m 페이스·영법별 거리·지난번 비교), 변화 요약(거리·100m 페이스)
- [x] 운동 종류 칩에서 '단체 운동' 묶음을 없애고 종목 이름 그대로 표시 (헬스·러닝·수영·축구·풋살 …)
- [x] 그날 기록 머리말을 기록 이름, 태그를 종목 이름으로 변경
- [x] 종류 칩을 한 줄로 두고 넘치면 좌우로 밀기 (터치 스와이프, 마우스 끌기·휠)
- [x] 운동/식단/체성분 탭이나 운동 종류 칩을 누르면 탭 줄이 화면 맨 위로 이동
- [x] 달력 날짜를 누르면 그날 기록이 화면 맨 위로 이동 (아래 내용이 짧으면 빈 자리를 덧대 끝까지 올림)

## 요약
- **무엇을/왜**: 데이터는 필요할 때 요청해서 파일에 직접 넣는 방식으로 바꾸고, 버튼은 없앴습니다. 수영·복싱처럼 혼자 하는 운동도 있어서 '단체 운동'으로 묶지 않고 종목을 그대로 보여 줍니다.
- **어떻게**: 예시 기록은 `RECORDS` 배열(파일 위쪽)에 있습니다. 구기 종목은 `kind: "meet"`에 제목이 종목 이름(예: `축구`, `풋살 모임` → `풋살`)이고, 수영은 `kind: "swim"`, meta는 `'30분 · 자유형 600m · 평영 300m'` 형식입니다.

## 검증
- 헤드리스 크롬에서 스크립트 오류 없음 확인
- 운동 종류 칩: 전체·헬스·러닝·수영·축구·풋살
- 수영 변화: 600m → 1,200m, 100m 3'20" → 2'50" / 축구 변화: 뛴 시간 58분 → 72분, 이동 6.1km → 7.6km
- 체성분 탭·운동 탭·날짜를 눌렀을 때 대상 위치가 화면 맨 위(8px)로 오는 것 확인

## 남은 이슈
