# 기록 탭 날짜 줄 상단 고정 + 누르면 달력으로

## 체크리스트
- [x] 기록 탭 운동·식단에서 고른 날의 날짜 줄('11월 9일 월요일 · 기록 N개')을 sticky로: 내리면 운동/식단(+종류) 줄 바로 아래에 붙음
- [x] 탭 줄 높이가 운동(종류 칩 있음)·식단(없음)에서 달라서 높이를 재어(`--calbar`) 붙는 위치를 맞춤 (아이패드 화면도)
- [x] 붙었을 때만 배경과 아래 선을 보이고, 위 탭 줄의 선은 숨겨 선이 한 줄만 보이게 함
- [x] 날짜 줄을 누르면(키보드 Enter/Space도) 달력이 탭 줄 바로 아래 오도록 부드럽게 올라감
- [x] 날짜 옆에 작은 위쪽 화살표 표시(누를 수 있다는 힌트), 마우스를 올리면 살짝 올라감

## 요약
- 무엇을: 그날 기록을 길게 내려 보는 동안에도 어느 날짜를 보고 있는지 보이게 하고, 바로 달력으로 돌아갈 수 있게 했습니다.
- 어떻게: 날짜 줄은 그날 기록 묶음 안에서 sticky라, 그날 기록이 끝나면 함께 밀려 올라갑니다. 붙음 표시는 기존 `stuckMark()`에 더했고, 올라가는 동작은 기존 `smoothTo()`를 씁니다.

## 검증 (헤드리스 크롬)
- 운동(11월 15일): 내린 뒤 날짜 줄 위쪽 = 탭 줄 아래쪽(103px), 붙음 표시 켜짐 → 누르면 달력이 탭 줄 바로 아래(111px)
- 식단(11월 18일): 날짜 줄 위쪽 = 탭 줄 아래쪽(59px) → 누르면 달력이 탭 줄 바로 아래(67px)
- 스크립트 오류 없음
