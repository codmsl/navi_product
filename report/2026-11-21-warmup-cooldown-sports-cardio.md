# 준비·마무리 운동 구조 개편, 스트레칭 자세·추가 화면, 구기 종목 분리, 헬스 유산소, 기록 탭 위로 이동 즉시 전환

## 체크리스트
- [x] 기록 탭: 위로 가는 이동(아래에 있을 때 운동·식단·종류 선택)은 애니메이션 없이 바로 전환. 아래로 가는 이동(날짜 선택)은 그대로 부드럽게
- [x] 운동 종류 목록에서 '스트레칭' 삭제 (예전 저장값에 있던 것도 제거)
- [x] 준비 운동 → 본 운동 → 마무리 운동 순서로 표시. 준비·마무리는 '준비 운동 · 5동작 · 운동 전 · 몸을 움직이며 풀어요' 한 줄만 보이고, 누르면 할 동작이 아래로 펼쳐짐
- [x] 오늘의 운동, 각 운동 종류 화면(헬스 루틴마다, 러닝, 구기 종목, 수영 등) 모두 같은 구조
- [x] 펼친 동작을 누르면 스트레칭 자세 자리(자세 영상 자리 + 쓰는 근육 + 자세 포인트)가 열림. 가볍게 뛰기·걷기 같은 몸풀기는 자세 없음
- [x] 스트레칭 동작 사전 ST_DB 70개: 부위(목·어깨, 가슴·등, 팔, 허리·코어, 엉덩이·고관절, 다리, 전신), 기구(맨몸, 고무 밴드, 폼롤러, 마사지볼, 벽·문틀, 의자·벤치), 동작 그림, 늘어나는 근육, 자세 포인트, 기본 양
- [x] 준비·마무리 운동 추가 화면: 헬스 종목 추가와 같은 화면(부위별/기구별, 찾기, 누르면 자세 자리·근육·포인트, 직접 적어서 추가)
- [x] 각 종류의 '루틴 수정'을 누르면 준비·마무리 운동도 함께 수정 (양 고치기, 빼기, 추가, 자동 추천으로 되돌리기). 별도 '수정' 버튼은 없앰
- [x] 운동 중 준비·마무리 체크 카드에 '자세' 버튼
- [x] 구기 종목 분리: '단체 운동' 종류를 없애고 축구·풋살·농구·배드민턴·배구·족구·테니스를 각각 종류로. 종목 화면에 그 종목 모임. 오늘 계획 바꾸기에도 종목별로. 예전 저장값 '단체 운동' → 고른 종목으로 바꿈. 구기 태그 이름 '단체' → '구기'
- [x] 헬스 유산소: 부위별·기구별에 '유산소' 추가, 트레드밀 걷기/달리기·실내 사이클·로잉 머신·천국의 계단·일립티컬·줄넘기 (그림·근육·자세 포인트 포함)
- [x] 루틴 예시에 유산소 1개씩 (하체: 트레드밀 걷기, 상체: 로잉 머신, 전신: 줄넘기)
- [x] 유산소는 1세트, 세트 표는 '강도 · 분'으로 기록. 기록 탭에서는 볼륨·최고 무게·최고 기록 계산에서 빼고 '강도 6 · 15분'처럼 표시

## 검증 (헤드리스 크롬)
- 스크립트 오류 없음
- 오늘의 운동(러닝): 준비 운동 → 본 운동 → 마무리 운동 순서, 접힘 확인
- 헬스 루틴 수정: 준비 운동(양 입력·빼기·추가) → 종목 → 마무리 운동 한 번에 수정
- 마무리 운동 추가 화면: 부위별 칩, 펼치면 자세 자리·늘어나는 근육·포인트
- 운동 중: 준비 운동 체크 + 자세 펼침, 트레드밀 세트 표 '강도 | 분', 지난번 '강도 6 · 15분'
- 기록 탭: 스크롤 1067에서 식단 → 50ms 안에 220(탭 줄 위치)으로 바로 전환
