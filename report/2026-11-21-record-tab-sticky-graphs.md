# 기록 탭: 화면 이동 정리, 고정 탭 줄, 운동 능력 변화 그래프 개편

## 체크리스트
- [x] 운동·식단 탭을 누를 때는 화면 이동 없음 (체성분 탭, 운동 종류 칩, 달력 날짜만 이동)
- [x] 다시 그릴 때 맨 위로 튀었다가 내려가던 동작 수정: 그리기 전후로 스크롤 위치를 지키고, 지금 위치에서 바로 부드럽게 이동
- [x] 아래 내용이 짧을 때 덧대는 빈 공간은 이동이 끝난 뒤에만 줄이도록 변경 (중간에 줄여서 튀는 것 방지)
- [x] 운동/식단/체성분 줄과 운동 종류 줄을 화면을 내리면 맨 위에 고정
- [x] 고정 줄 디자인: 고정되기 전에는 배경 없음, 고정되면 반투명 막과 아래 가는 선만 표시. 식단 탭 바로가기 줄에도 같은 디자인 적용
- [x] 날짜를 누르면 그날 기록이 고정 줄 바로 아래로 이동
- [x] A: 최근 4주와 그 전 4주 비교 (횟수 · 총 운동량 · 평균 실력, 헬스는 1회 평균 볼륨)
- [x] B: 주별 흐름. 위 칸은 주간 운동량 막대, 아래 칸은 주간 평균 실력 선 (단위가 달라 한 축에 겹치지 않고 두 칸으로 나눔), 누르면 그 주 기록 표시
- [x] C: 헬스만, 종목을 골라 그날 최고 무게(맨몸은 횟수)를 날짜 간격 그대로 표시, 최고 기록을 넘은 날은 채운 점
- [x] D: 지금까지 최고 기록 (2주 안에 세운 건 '새 기록' 표시)
- [x] 그래프를 볼 수 있게 예시 기록 추가: 헬스 10회, 러닝 6회 (9/27~10/23, 예시 기준일)

## 요약
- 종목별 지표: 러닝(거리 / 평균 페이스), 수영(거리 / 100m 페이스), 구기 종목(뛴 시간 / 이동 거리), 헬스(볼륨 = 무게×횟수, 실력은 C에서 종목별로)
- 기간 칩(전체·3개월·한 달)은 B와 C에 적용. A는 항상 최근 4주, D는 전체 기간

## 검증
- 헤드리스 크롬에서 스크립트 오류 없음
- 화면 중간(스크롤 500)에서 날짜를 눌러도 위치가 그대로(500)였다가, 그날 기록이 고정 줄 아래로 이동하는 것 확인
- 식단 탭으로 바꿀 때 스크롤 위치 유지 확인
- 헬스·수영·러닝·축구 변화 카드 화면, 다크 모드 고정 줄 색 확인
