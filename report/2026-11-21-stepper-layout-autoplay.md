# 측정 기록 숫자 조절 조회, 운동 종류 화면 배치 되돌리기, 자세 애니메이션 자동 재생

## 체크리스트
- [x] 측정 기록 '직접 설정': 달력 대신 시작·끝 날짜의 년·월·일을 ▲▼로 조절
- [x] 조절하는 동안에는 막지 않고, 잘못되면 아래에 빨간 주의 문구 (시작 > 끝, 끝이 오늘 뒤, 3개월 초과). 그 상태로 조회하면 같은 안내를 띄우고 조회하지 않음
- [x] 월을 바꿨을 때 그 달에 없는 날이면 말일로 맞춤 (예: 3/31 → 2월이면 2/28)
- [x] 준비 → 본 → 마무리 순서 배치는 오늘의 운동에만 남기고, 운동 종류 화면은 예전 배치로: 루틴 카드 + 아래 '준비 · 마무리 운동' 카드(두 목록을 펼친 채). 헬스는 펼친 루틴 안에 이 카드
- [x] 준비·마무리 운동 수정은 그 종류의 '루틴 수정'으로 함께 (카드 따로 수정 버튼 없음)
- [x] 자세 영상 자리 → '자세 애니메이션' 자리로: 재생 버튼 없이 항상 반복 재생. 운동 중 일시정지하면 애니메이션도 멈춤
- [x] 움직임 종류별 박자 (내려갔다 올라오기 2.4초 / 제자리 반복 0.6초 / 크게 돌리기·흔들기 1.6초 / 멈춰서 늘리기 숨 4초)와 박자 막대·박자 안내 문구
- [x] 가볍게 걷기·제자리 뛰기·조깅·줄넘기·페달·방향 바꿔 달리기 등 가벼운 몸풀기에도 애니메이션 자리와 그림 (걷기·뛰기·클라이밍 그림 추가)

## 검증 (헤드리스 크롬)
- 스크립트 오류 없음
- 직접 설정에서 시작 월을 4번 내려 6/21~11/21 → '기간이 3개월을 넘어요' 주의 표시
- 헬스 하체 루틴: 종목 목록 아래 '준비 · 마무리 운동' 카드
- 수영 루틴 수정: 동작 목록 + 아래 카드에서 준비·마무리 운동 편집
- 운동 중: 바벨 스쿼트 애니메이션 자리(재생 버튼 없음, 박자 막대·안내)
