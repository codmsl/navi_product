# 자세 애니메이션 자리 정리, 운동 중 종목 교체, 계획 수정 두 단계 선택, 종류 화면 이번 주 계획 편집, 종류마다 루틴 여러 개

## 체크리스트
- [x] 자세 애니메이션은 자리만 (움직임·박자 막대 제거). 실제 앱에서는 재생 버튼 없이 자동 반복될 자리
- [x] 운동 중 준비·마무리 운동: 지금 할 동작(첫 번째로 안 한 동작)은 자세 애니메이션 자리를 기본으로 펼침. '자세' 버튼으로 다른 동작도 열고 닫기
- [x] 운동 중 종목 교체: 헬스 운동 중 종목 이름 옆 '교체' (아직 세트를 기록하지 않은 종목만)
- [x] 오늘의 운동 '계획 수정하기': 요일을 누르면 1단계 운동 종류(내 운동 종류 + 쉬기) → 2단계 그 종류의 루틴
- [x] 각 운동 종류 화면 위 '이번 주 계획' 7요일 버튼: 누르면 그 종류의 루틴 중에서 고르거나 '이날은 쉬기'. 오늘은 테두리로 표시. 아래 설명 문구 제거
- [x] 헬스 외 종류도 루틴 여러 개: 루틴 카드(펼치기), 루틴 수정에서 이름·동작·양 고치기, 루틴 추가·지우기 (러닝은 목표 계획 아래에 러닝 5km·인터벌·3km 루틴)
- [x] 수영·요가처럼 실시간 운동 화면이 없는 종류도 계획에 넣기 (kind 'etc'): 오늘의 운동에서 '○○ 기록하기'로 시간(수영은 거리도) 기록 → 오늘 계획 달성, 기록 탭 종류 칩·변화 카드·최고 기록에 표시
- [x] 계획에 종류·종목(type·sport)을 함께 저장, 홈 이번 주 계획 태그도 종목 이름으로

## 검증 (헤드리스 크롬)
- 스크립트 오류 없음
- 러닝 화면: 이번 주 계획(토·월), 목표 계획 카드 아래 루틴 3개
- 수영 화면에서 화요일 → '수영 기본' 고르기 창
- 계획 수정: 일요일 → 러닝 → 러닝 5km / 인터벌 / 3km
- 오늘을 요가로 바꾸고 '요가 기록하기' 저장 → 오늘 계획 달성, 기록 탭에 '요가' 칩과 변화 카드
- 헬스 운동 중 '교체' 버튼 표시
